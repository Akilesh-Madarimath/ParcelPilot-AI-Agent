# AI Tool Usage

AI coding assistants were used during development to accelerate implementation, debugging, code restructuring, and documentation.

They were primarily used for:

- Debugging Python and Streamlit errors
- Improving backend function structure
- Implementing confirmation-gated escalation logic
- Reviewing edge cases around authorization and ticket ownership
- Generating and refining documentation
- Troubleshooting deployment issues

The final implementation was tested locally and through the deployed Streamlit application.

AI assistance was used as a development aid; implementation decisions, testing, validation, and final integration were performed by the developer.
